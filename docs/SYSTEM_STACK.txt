================================================================================
SECURITY & HASHING
================================================================================

User passwords ............... bcrypt (password_hash / password_verify)
Session Bearer tokens ........ SHA-256 hash stored in sessions.token_hash
OTP codes .................... stored in DB with expiry (otp_codes table)
Login brute-force ............ AUTH_LOGIN_FAILURE_THRESHOLD
OTP rate limits .............. api/otp_guard.php (attempts, lockout, hourly cap)
Auth header .................. Authorization: Bearer <token>
Session idle timeout ......... SESSION_IDLE_TIMEOUT_MINUTES (default 30)
Session absolute lifetime .... SESSION_ABSOLUTE_LIFETIME_HOURS (default 12)
Login MFA .................... OTP after password (AUTH_LOGIN_OTP_REQUIRED=1)
